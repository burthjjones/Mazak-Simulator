MAZATROL Smart Lernsimulator – iPad App (PWA)

Installation auf dem iPad:
1. Den Ordner auf einen Webserver mit HTTPS hochladen.
2. index.html in Safari öffnen.
3. Teilen -> Zum Home-Bildschirm.
4. App vom Home-Bildschirm starten.
5. Nach dem ersten Laden funktioniert sie auch offline.

Wichtig:
Eine PWA kann nicht zuverlässig direkt aus der Dateien-App installiert werden.
Für Home-Bildschirm + Offline-Modus muss sie über http/https ausgeliefert werden.
